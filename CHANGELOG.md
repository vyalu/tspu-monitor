# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).
Каждая версия отсюда автоматически публикуется как [релиз на GitHub](https://github.com/vyalu/tspu-monitor/releases).

## [1.2.0] — 2026-11-12

### Исправлено
- Сайт, который перенаправляет на другой адрес (например, `example.ru` → `www.example.ru`), раньше считался рабочим по первому ответу, даже если конечный адрес заблокирован. Теперь монитор, как браузер, проходит по перенаправлениям (до 5) и проверяет каждый адрес полностью: DNS, TCP, TLS, загрузку.

### Добавлено
- Статус «сервер отказал в доступе (HTTP 403/451)» — сайт сам не пускает: геоблокировка для российских IP или защита от ботов.
- Статус «сервер ответил ошибкой HTTP» — 404, 5xx или зациклившиеся перенаправления.
- Номер версии в шапке страницы и в журнале контейнера.
- Автоматические релизы на GitHub по тегу версии.

### Изменено
- Запрос к сайтам идёт с заголовками обычного браузера. Контрольные сайты по-прежнему оцениваются только по сетевой доступности, без учёта кода ответа.

## [1.1.0] — 2026-11-09

### Добавлено
- Новое оформление README: баннер, скриншоты, описание возможностей.
- Демо-стенд с выдуманными данными и скрипты для картинок (`tests/demo/`).

### Исправлено
- Фраза в окне тревоги: «Подан звуковой сигнал» вместо «Отправлено звуковой сигнал».

## [1.0.0] — 2026-11-09

Первая публичная версия.

- Проверка по шагам: DNS → TCP → TLS → загрузка; статусы блокировки по SNI, по IP / белому списку, TCP 16-20, подмены DNS и сертификата.
- Вердикт по контрольным сайтам: режим белых списков, отсутствие интернета.
- Тревога в браузере: окно поверх страницы, звук, уведомление, мигающая вкладка.
- История за сутки и неделю, выгрузка CSV, диагностика при сбое (Globalping, сверка DNS, трассировка).
- Вход администратора, просмотр без входа, Docker с ограниченными привилегиями.
